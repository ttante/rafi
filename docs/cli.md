# CLI Reference

This file is a generated snapshot of the Commander help output for the current `rafi` and standalone `ai-foreman` CLIs. The source of truth is the built-in help generated by the command tree in `packages/rafi/src/index.ts` and `packages/ai-foreman/src/cli/*.ts`.

To refresh this reference, rebuild if needed and capture the relevant `--help` output from:

- `node packages/rafi/dist/index.js --help`
- `node packages/rafi/dist/index.js <command> --help`
- `node packages/rafi/dist/index.js tickets <subcommand> --help`
- `node packages/ai-foreman/dist/index.js --help`
- `node packages/ai-foreman/dist/index.js <runtime-command> --help`

Commander help does not visually mark every `requiredOption`. Source-derived required options are:

- `rafi start <project>` requires `-s, --steps <n>`.
- `rafi tickets cancel <ticketId>` requires `--summary <text>`.
- `rafi tickets discover` requires `--summary <text>`.
- `rafi tickets accept-future-work <futureWorkId>` requires `--ticket-id <id>` and `--order <n>`.
- `rafi tickets complete <ticketId>` requires `--evidence <text>` unless `--validation-result not_applicable` is used.

### `rafi start --help`

```text
Usage: rafi start [options] <project>

Enlist a builder and drive it through a batch of N steps.

Arguments:
  project                   path to the project directory the builder works in

Options:
  -s, --steps <n>           number of steps to drive
  -a, --agent <agent>       builder agent (claude | codex) (default: "claude")
  -m, --model <model>       override the builder's model
  -r, --resume <sessionId>  resume a prior builder session
  --continue                resume the most recent logged session for this
                            project
  -t, --tickets <path>      path to ticket file (.md, .txt, .yaml, …) — passed
                            to the builder as context
  -y, --yes                 skip pre-flight confirmation prompt
  --effort <level>          reasoning effort level (low|medium|high|xhigh)
  --fast                    fast mode — lower latency (maps to effort=low for
                            codex)
  --no-qa                   disable per-ticket QA review (enabled by default)
  --branch-per-ticket       run each selected structured ticket in an isolated
                            git worktree and branch
  --create-pr               push each successful ticket branch and create a
                            GitHub PR (implies --branch-per-ticket)
  --base <ref>              base ref for root ticket branches (default: current
                            branch or HEAD)
  --branch-prefix <prefix>  branch name prefix for ticket branches (default:
                            "rafi")
  --max-branch-depth <n>    maximum selected branch stack depth (default: "2")
  --pr-ready                create ready-for-review PRs instead of draft PRs
  --keep-worktrees          keep successful ticket worktrees for inspection
  --ticket <id>             ticket id to continue in branch mode; repeat for
                            multiple tickets (default: [])
  -h, --help                display help for command
```
